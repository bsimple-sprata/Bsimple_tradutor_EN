# Traduções para inglês UK

Sempre que criares ou alterares texto em inglês de UK neste projeto:

1. Antes de traduzir, consulta a página de terminologia aprovada no repositório oficial de traduções no Confluence (na página 772866077), através do ficheiro "Get-ConfluencePage.ps1" ou outro método que estejas a usar.
2. Se não tiveres ligação ao confluence, pede ao utilizador que configure uma ligação de leitura ao Confluence via token API antes de prosseguir.
3. Indica as diferenças encontradas e faz as substituições necessárias para responder às regras e sugestões da página 772866077 no Confluence.
