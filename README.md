# Bsimple_translator_EN

Este repositório é a fonte de verdade para orientar agentes de IA na tradução e validação de items de Azure DevOps de Português para Inglês, com base no dicionário e nas expressões aprovadas no Confluence.

O objetivo deste repositório não é armazenar traduções finais, mas sim guidelines reutilizáveis para diferentes agentes e ferramentas.

```text
├── README.md
└── DOCS/

    ├── CODEX/

    └── Instruções Gerais/

```

## Conteúdo esperado

Este repositório deve evoluir para manter:

- palavras aceites e preferidas em inglês;
- expressões aprovadas para utilização no Confluence;
- terminologia proibida, ambígua ou a evitar;
- convenções de escrita, tom e estilo;
- regras para títulos, descrições, documentação técnica e comunicação interna;
- instruções reutilizáveis para agentes de IA.

## Princípios base

- Confirmar sempre o dicionário e as expressões aprovadas no Confluence antes de propor uma tradução.
- Utilizar Inglês europeu (British English).
- Preservar o significado funcional e técnico do texto original.
- Evitar terminologia ambígua, proibida ou não validada.
- Manter as instruções organizadas por agente, com uma base comum reutilizável.
