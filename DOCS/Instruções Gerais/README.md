# Instruções Gerais

Estas instruções aplicam-se a todos os agentes de IA utilizados neste repositório.

## Objetivo

Traduzir e validar items de Azure DevOps de Português para Inglês com base no dicionário e nas expressões aprovadas no Confluence.

## Regras base

1. Verificar sempre o dicionário e as guidelines aprovadas no Confluence antes de traduzir.
2. Utilizar Inglês europeu (British English).
3. Preferir terminologia aprovada e consistente entre items.
4. Evitar termos proibidos, ambíguos ou não recomendados.
5. Preservar contexto funcional, técnico e de negócio.
6. Ajustar tom e estilo ao tipo de conteúdo: título, descrição, documentação técnica ou comunicação interna.
7. Quando existir dúvida terminológica, sinalizar a ambiguidade em vez de inventar uma tradução.

## Âmbito deste repositório

Este repositório deve conter apenas guidelines, instruções e documentação de suporte para agentes. Não deve ser utilizado para armazenar traduções finais de items.
